КАК ОТКРЫТЬ САЙТ UIDOMHOME НА WINDOWS

1. Полностью распакуйте ZIP-архив через «Извлечь всё».
2. Откройте распакованную папку.
3. Дважды нажмите OPEN_SITE_WINDOWS.bat.
4. Ничего в чёрном окне нажимать не нужно. Не закрывайте его, пока пользуетесь сайтом.
5. Браузер откроется автоматически по адресу http://localhost:5173

Первый запуск:
- нужен интернет;
- установка компонентов может занять несколько минут;
- если Windows покажет предупреждение, выберите «Подробнее» → «Выполнить в любом случае».

Если браузер не открылся автоматически, вручную введите:
http://localhost:5173

Как выключить сайт:
закройте чёрное окно UIDOMHOME LOCAL SERVER.

Важно: запускайте BAT-файл только из распакованной папки, не из ZIP-архива.
